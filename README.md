# Formidable — planning des formations (100 % hors ligne)

Ouvrir `formidable.html` dans Chrome ou Edge (double-clic). Aucun serveur, aucune connexion :
une politique CSP intégrée interdit tout accès réseau.

- Sources dans `src/` ; `python3 src/build.py` régénère `formidable.html`.
- Données : stockage du navigateur, ou fichier `.json` partagé (Import / Export → Fichier de données partagé).
- Import du planning Excel : Import / Export → « Importer le planning Excel ».
